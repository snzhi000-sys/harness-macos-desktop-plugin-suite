# 桌面宠物

[English](README.md) | 中文

内置角色选择器、Cordis Host 与透明 Electron 桌面窗口。本地 Dev 和 Stable 插件包含 22 个 Live2D 模型版本和龙骨伙伴萌妹，每个角色自动使用独立的动画驱动。两个通道均包含本插件；公开分发仍需资源许可证审核。

## 使用

打开 **🐾 桌宠**，在独立滚动的角色列表中浏览或按名称搜索。点击任意角色行即可立即保存选择并切换桌宠。右侧显示角色立绘，底部按钮始终可见。 萌妹排在第一位。“天命之子”条目与插件内资源均移除；已保存的被移除角色回退到萌妹。

调整 **角色显示大小**、**开启动画**、**保持在窗口上方** 后点击 **保存**。保存基础设置保持当前显示状态；**显示** 恢复桌宠，**隐藏** 释放原生渲染窗口。使用右上角 × 或 Escape 关闭设置，两者都会释放预览。大小和开关仅在保存后生效，角色选择立即生效。

轻轻摸头、点击身体或拖动角色。动作、表情、视线和物理效果取决于模型本身。部分版本属于同一个角色或不同服装，23 套造型合并为 19 位伙伴。已确认的 Mori 与户山香澄服装共用一个角色项，详情中选择服装即刻切换并保存；身份未确认的模型保持独立。互动无需 API Key，也不请求模型。 左键只触发互动，右键打开菜单。输入框位于适配后立绘下沿 12 CSS 像素处，并限制在窗口内。 设置中展开「动作调试」，按住动作或表情按钮时，立绘与已显示的桌宠同步预览；松开、取消、失焦、切换标签或关闭设置后恢复正常动画。需先开启并保存动画，支持空格和 Enter 按住操作。同源且按角色限定的预览信号在一秒未续期后自动结束。

动作模块提供 `category: body | mouth` 字段，只有萌妹的 a/i/o/m 属于嘴型；设置按类别展示预览按钮。实际显示且开启动画的桌宠空闲满 60 秒后随机执行一个可用肢体动作，尽量不连续重复。点击、菜单、拖拽、暂停或隐藏会打断动作；执行完成回到待机，再开始下一轮计时。设置立绘不自动执行。`automaticActionIntervalMs` 是 Cordis 部署配置，默认为 60000；待机、鼠标跟随控制轨道及默认表情不参与自动抽选。

Cubism 在切换动作和恢复待机时清空旧动作队列，恢复原有参数及 Cubism 3/4 部件透明度，同时清理表情队列。中断预览和没有待机动作的模型也走同一恢复路径，避免备用手臂部件残留显示。

Cubism 3/4 开启 `CubismConfig.setOpacityFromMotion`，并在运行库解析前把动作曲线稳定排列为 Model → Parameter → PartOpacity。部分导出混排曲线，固定版本运行库否则会跳过后续曲线，并把透明度当作虚拟参数。原始素材和关键帧数值保持不变。播放验收检查 main_2 与 touch_body 执行中的备用/默认手臂透明度，不能只检查松手之后。

## 对话与声音

语音分句识别中文省略号和至少三个连续英文点作为停顿边界，保留小数。流式处理等待标点串结束，将完整省略号留在前一句；后续括号动作归属下一段。省略号快照验证每段及最后问句都进入播放。当前音色的真实样本保留了尾句，但这不能确定偶发漏读的原因。

情绪输出固定为五个按顺序排列、以“我”书写的纯文本字段：当前心情、态度方向、内心波澜、语气色彩、情绪基调。Prompt 禁止话题引导、条件式回复指令及虚构人设事实。Host 为自定义情绪 Prompt 附加输出要求，不覆盖自定义内容；与旧默认完全一致的 Prompt 自动升级。格式整理仅修复字段间空白和合并行，缺失、重复、乱序或非第一人称字段会使更新失败并保留上次情绪。格式校验不判断情绪语义质量。

「Prompt 管理」分别编辑对话和情绪 Prompt。`{{情绪模拟}}` 注入最新已完成的情绪文本；不含变量的自定义 Prompt 原样保留。情绪共用桌宠独立模型：首轮先分析用户消息再回复，之后每次完成回复后默认分析双方最近八条消息，`emotionHistoryMessages` 可设为 1–100。情绪 Prompt 中的 `{{聊天记录}}` 在指定位置展开为按时间排列的“糖糖：…… / 用户：……”文本，`emotionCharacterName` 可修改角色称呼；不再额外追加 JSON 历史。首轮情绪包含用户第一条消息。旧轮数字段按原数值迁移为消息条数，旧自定义模板显式补入历史变量；删除变量则不注入历史。后续回复不等待后台更新。失败时保留上次情绪，取消或过期任务不能覆盖新结果。情绪文本和请求独立于聊天消息与 TTS。新对话清空情绪，重新打开会恢复；标签页显示当前文本及更新状态。

「动作与关键词」使用 `actionPresets` 按角色服装保存有序预设，包含稳定 ID、名称、原始动作引用、启用状态、归一化权重及关键词。旧 `actionKeywords` 迁移为 100% 预设，不改私人历史。仅匹配括号内的字面关键词，最长优先，等长按预设顺序；支持复制、删除、上移，保存后提交草稿。龙骨权重可设为 0%–100%；其他引擎在完成涉及部件显隐的低权重适配验证前保留 100%。拖动滑块更新当前预览状态而不重启时间轴；松开、失焦、换标签、关闭或预览租约过期时恢复。编辑其他服装不会切换桌宠。开启 TTS 时，命中的肢体动作按预设权重保持到语音片段完成、取消或失败；无语音时限时播放，直接互动可打断。说话与简洁输入框焦点独立控制跟随回正。

「亲密度」通过 `intimacyLevels` 编辑任意多个等级的名称、起始分数、结束分数与描述，两端分数均可直接修改。区间从 0 开始连续排列，不允许重叠或遗漏，最后一级结束分数留空表示无上限。仅保存起点的旧设置会迁移为相同的有效区间。默认范围是 0–10、11–20、21–40、41–65、66 以上。每完成一轮非空用户/AI 回复，为私有会话加 1 分且只计一次；中断、失败、连接测试和情绪请求不计分。已有聊天从 0 开始，不补算历史。重新打开保留分数，新建对话清零但保留等级设置。情绪 Prompt 中的 `{{亲密情况}}` 展开为当前分数、等级名称和描述，首轮情绪读取 0 分，回复后情绪读取加分后的状态。完全匹配旧默认的 Prompt 自动加入变量，自定义 Prompt 保留内容并提供插入按钮。展开后的 Prompt 保存在辅助请求证据中，不写入聊天消息。

回复气泡保留文字和括号原样；嵌套或尚未闭合的中英文括号片段使用 `#948b81`，对白保留 `#534636`，模型文字不会解释为 HTML。语音过滤与聊天原文不受该视觉区分影响。

从桌宠菜单打开「聊天」，角色下方显示文本输入框。「关闭聊天」只收起输入框，不重置记录或取消回复。此输入框与设置 →「聊天记录」共用最近一次对话和有上限的模型上下文；设置内嵌完整记录、录音、停止及新对话功能，不创建另一个原生窗口。Enter 发送、Shift+Enter 换行，中文输入法组合期间不发送。录音结果可修改后显式发送，开始采集会停止朗读。麦克风仅允许内嵌聊天页申请音频权限；录音转换为单声道 16 kHz PCM，识别后丢弃。 简洁输入框在当前活动窗口内获得焦点时，鼠标跟随平滑回正并暂停；失焦、窗口失活或关闭输入框后解除暂停，且须同时满足语音已结束才恢复跟随。

「对话」与「声音」页配置桌宠自己的方舟地址、模型和独立模型/TTS/ASR Key，不继承 Harness 模型设置。默认与克隆音色匹配各自 V3 资源；支持已有克隆 speaker ID，不包含音色训练。自动朗读开关立即保存，关闭时取消语音但保留文本生成；其他表单修改需要保存。「保存并试听音色」先保存当前表单再合成；音色 ID 去除首尾空格，`S_` 自动匹配克隆资源。配置加载期间禁用表单编辑，避免迟到响应覆盖输入；界面明确显示自动朗读状态。一轮回复固定使用开始时的配置，修改在下一轮生效。

中文及英文括号内的旁白只从流式 TTS 文本移除，支持嵌套，原回复和历史不变。短感叹词与后一句合并，只有实际桌宠播放声音，完整短句依次合成并进入有上限的播放队列。头顶气泡展示 AI 回复，直到文本生成及全部语音播放确认完成；暂停朗读时气泡保持。没有播放语音时按字数显示 2–10 秒，互动提示不会覆盖回复。字级时间戳加拼音映射到 a/o/i/m；标点不分占发音时长，缺字优先补入可用时间空隙；字幕不兼容或缺失时使用估算时间，播放时根据静音闭嘴。Web Audio 时钟控制嘴型并支持暂停/恢复。尚未接入口型驱动的 Live2D 角色仍支持文字与声音。离开设置的聊天记录标签会释放麦克风；隐藏、切换角色或卸载会取消对话与音频任务。

`conversation.json`、`voice-credentials.json` 与 `conversation-session.json` 与外观设置一同保存在 `DSH_HOME/state/dsh-desktop-pet`。Key 使用权限 0600 的私有文件，不是加密存储；GET 仅返回是否配置。Key 留空保持原值，清除后保存才删除。请求记录保留实际提交模型的消息，新对话将旧记录归档在本地。这些文件不进入发行包。

`node scripts/conversation-smoke.mjs` 验证无需密钥的真实 UI 装配快照；显式设置 `PET_LIVE_CREDENTIAL_FILE` 才启用私有文件服务测试。`scripts/conversation-electron-smoke.mjs` 使用已知的虚拟麦克风测试原生采集与真实 ASR，物理麦克风和音色主观质量仍需用户验收。官方协议来源与快照哈希保存在调研产物中，产品依赖固定在 lockfile。

## 内置立绘

`assets/catalog.json` 管理稳定标识、名称、相对入口与预设互动配置。Host 直接从插件包读取模型和 Core。新增角色在开发时加入、检查、预览并重新打入 Dev 包；用户无需导入目录、选择驱动、调整动作绑定或填写路径。PNG 立绘模式及其设置已移除。

`scripts/prepare-builtin-assets.mjs` 将此前下载并固定版本的调研资源整理到 Git 忽略的本地资源目录。脚本仅复制模型依赖及已确认的动画配置，不复制用户设置、凭据、私人模型库索引或包含绝对路径的来源文件。本地资源包附带来源说明；人物素材和 Cubism Core 遵循各自条款，本地打包不构成公开分发授权。

扩展资源由 `scripts/additional-models.json` 与 `scripts/prepare-additional-models.mjs` 固定来源，校验依赖 blob 哈希，并要求至少六个独立动作引用。`scripts/verify-additional-models.mjs` 在入库前用真实驱动播放全部声明动作。四组资源共新增十二个模型、152 个动作。

## 龙骨接入

`mouthRecipes.mengmei` 将拼音符号映射为一个 a/o/i/m 原始嘴型及归一化权重。可编辑的初始配方为 e→i 55%、w→o 45%、y→i 70%，也支持配置 u/ü/v。这些是视觉近似，不是供应商新增网格或精确音素对齐。字词时间与拼音在播放前保留发音符号，播放器按当前角色解析已保存配方；连续使用同一网格但权重不同的 cues 仍进行融合。手动嘴型预览暂时压低自动嘴型层，音频时钟继续推进；结束或取消后所有说话权重归零。嘴型配方按发音匹配，不使用动作关键词；肢体预设仍匹配括号文本。修改配置从下一轮回复生效，不改变已排队音频。`node scripts/weighted-actions-smoke.mjs` 验证官方运行库多档权重形变、底层恢复及同网格的权重切换。

萌妹通过官方运行库的 `zhuan` 骨骼叠加偏移跟随鼠标，保留 `zhuanshen` 身体及头部约束链。应用补充的「左右／上下」时间轴保留在资源中，但鼠标跟随期间不播放。角色配置将身体位移限制在左右半径 350、上下半径 300 个骨架单位的椭圆内，身体灵敏度为 2、眼球偏移为 18，采用 0.18 秒平滑。原生鼠标事件在窗口外仍有效；拖拽、动作预览、说话及简洁输入框获得焦点时回正，关闭动画复位并静止，手势、表情和嘴型独立叠加。

在插件目录运行 `node scripts/prepare-dragonbones.mjs <原始导出目录>`，从三个原始文件准备萌妹。脚本为物理约束添加名称前缀，保留骨骼和 IK 时间轴名称，清除导出的张嘴启动动作，下载固定版本的官方驱动并记录来源哈希。`--resources-only` 保留固定运行库，只更新素材并补齐应用跟随轨道。点击与释放使用供应商 `wuxiong`，其他互动、口型及跟随参数保持不变。构建后通过 `node scripts/dragonbones-smoke.mjs` 生成预览图。重新整理 Live2D 资源时会保留龙骨及已验收扩展角色。

渲染器使用 DragonBonesJS 6.0.2 分支的提交 `7b2d9f700d1719db2c5d89a6fa36c85d7f092501` 和 PixiJS 8.9.2；运行库 master 分支会拒绝此 6.0 资源。Live2D 在独立文档中保留 PixiJS 6.5.10。桌宠统一推进动画时钟，并移除固定版本适配器自动注册的 shared ticker 回调。销毁时释放骨架、工厂数据、贴图及画布。

萌妹保留 13 个供应商动画，补充两个应用跟随控制轨道，并保留全部 117 个约束。待机、交互、表情和嘴型使用独立动画组，并设置 `resetToPose=false`；嘴型 FFD 覆盖待机嘴部变形，同时保留面部骨骼运动。渲染器的 `speech.start({ cues, duration }, clock)` 接受按时间排序的 `{time, shape}`，时间单位为秒，姿态为 `a`、`o`、`i`、`m`。调用方提供 `() => audio.currentTime` 等音频播放时钟，暂停音频即可保持当前嘴型，中断时调用 `speech.cancel()`。时间轴结束会闭嘴；关闭动画拒绝新口型并取消已有时间轴，销毁停止所有口型。

对话播放器通过该驱动提供真实合成音频和字时间戳拼音 cues。四种已有嘴型近似表现说话，不代表完整音素对齐。`dragonbones-smoke.mjs` 独立检查固定 cues、手势、暂停和资源释放。 四个常驻的官方动画状态用归一化权重融合原有嘴部网格，标准过渡为 0.2 秒，不同元音在中点经过 m；短音节将融合上限缩至剩余时长的一半，下限 40 毫秒，让短促感叹词及时张嘴。说话专用派生状态排除 `i` 中的嵌套方向轨道，避免发音改变身体朝向。连续音节不在每个字尾强制闭嘴，连续静音 90 毫秒后才闭嘴，避免波形短暂空隙反复切嘴。`prepare-dragonbones.mjs --profile-only` 只刷新维护配置，不复制素材或下载运行库。 说话时嘴型权重归一化；默认和整句结束后的四个说话状态权重均为 0，结束用 0.2 秒淡出恢复待机嘴形。m 只用于说话中的闭口过渡，不作为静止嘴形。固定版本兼容修正让已完成的单帧 FFD 继续参与权重融合；待机未覆盖的内嘴槽使用零形变底层，防止残留。

## Spine 驱动开发

源码包含独立的官方 Spine WebGL 4.2 驱动与描述符分派。运行 `node scripts/prepare-spine-runtime.mjs [官方包.tgz]` 准备固定校验和的运行库及许可证。角色清单条目使用 `kind: 'spine'`、JSON 入口、atlas 与交互配置。描述符检查会拒绝配置中没有有效关键帧的动作，包括只有名称的空嘴型。供应商提供的 Spine 萌妹因贴图组装仍有问题，未加入内置列表；保留已验收的其他内置项。

渲染器支持透明区域命中、缩放、反馈轨道、动画暂停、可选的音频时钟嘴型与显式 GPU 释放。页面销毁会取消在途请求；绘图上下文丢失时释放渲染器，提示重新选择角色。`node scripts/spine-smoke.mjs <导出目录>` 独立验证构建后的驱动，不改变角色准入结果；生命周期检查通过不代表素材效果正确。官方 Spine 运行库与角色素材分别遵循自身许可。

## 状态与生命周期

设置版本 2 除版本字段外，仅包含 `modelId`、`height`、`animated` 和 `alwaysOnTop`。读取版本 1 时保留基础偏好，并按旧导入角色名称映射至内置标识。原有私人素材不删除，当前 HTTP 设置接口拒绝已移除字段。设置仍位于 `DSH_HOME/state/dsh-desktop-pet`；原生窗口的位置和显示状态保存在通道独立的 userData。

Host 路由限制本机同源访问，并拒绝资源路径越界和符号链接逃逸。导入、修改角色配置和文件选择入口已移除。预览随弹窗关闭而释放，迟到响应不能重新打开预览。Cordis 卸载释放 Client 与原生窗口租约。不再提供会话关联设置或自动会话订阅；本地 touch/click CustomEvent 仍可使用。

## 验证

运行 `npm run build`、`npm test`、`npm run test:browser` 和 `npm run test:electron`。浏览器检查使用真实 Host、编译后 Client、空数据目录和实际界面快照，覆盖两种尺寸布局、列表末项切换、持久化和关闭竞态。原生检查覆盖透明区域穿透、拖动、重启恢复、暂停动画、大小调整、隐藏与显示和卸载。

在统一工程根目录通过标准 `npm run product:dist:dev` 构建。随后运行 `scripts/product-v2-smoke.mjs`，以空用户数据且没有导入素材的方式检查最终包，验证执行文件哈希、内置资源、角色切换、实际动画和清理。`scripts/launch-live2d-demo.mjs` 启动专属持久体验版。
