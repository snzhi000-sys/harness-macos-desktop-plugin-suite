# Agent Note: 龙骨桌面伙伴的既有动画

Status: implemented

[English](2026-09-08-desktop-pet-dragonbones.md) | 中文

## Problem

萌妹是 DragonBones 6.0 资源，包含网格嘴型、表情、手势和物理效果。Cubism 渲染器无法解释其骨架。DragonBonesJS 默认分支也拒绝这一格式；兼容分支遇到不同类型的约束重名时，会跳过三个物理约束。

## Decision

桌宠插件根据角色清单中的类型自动分派驱动，将萌妹与 10 个 Live2D 版本一同内置。DragonBonesJS 6.0.2 分支固定为 `7b2d9f700d1719db2c5d89a6fa36c85d7f092501`，搭配 PixiJS 8.9.2。资源准备为物理约束及其物理时间轴引用添加名称前缀，保留骨骼和 IK 名称，全部 117 个约束可用。

每个桌宠或预览文档只加载当前角色所需的运行库。Live2D 保留 PixiJS 6；龙骨使用 PixiJS 8，并移除固定版本适配器自动注册的 shared ticker。渲染器负责时间推进和资源销毁。独立动画组保留身体动作和表情变换，嘴型组通过 FFD 控制发音姿态。

嘴型控制器接受带时间戳的既有嘴型和调用方持有的音频时钟。音频暂停时保持嘴型，跳转时跟随，结束或取消时闭嘴，并随动画开关停用。它不推断音素，也不订阅 Harness 会话。角色选择器和设置格式不依赖动画技术。

## Alternatives considered

**使用 master 或降低导出版本号。** master 缺少所需格式和约束能力，修改版本标签无法补齐效果。

**将全部角色升级至 PixiJS 8。** 现有 Cubism 驱动使用 PixiJS 6，独立文档避免把其兼容性与新增角色绑定。

**每次切嘴型都重置整个动画。** 这会丢弃同时播放的身体和表情动作。不重置的分组姿态能够保留这些层，也无需将骨骼资源转为逐帧图片。

## Consequences

鼠标跟随使用素材的方向控制骨骼及小幅眼球骨骼偏移，在官方时钟推进前更新。素材原有眼球约束的横向注视很弱，因此通过有限的眼球偏移补足可见效果，保留网格权重与约束。中立脸部位置作为锚点避免反馈漂移，圆形范围限制确保斜向输入不超出验证幅度。拖拽和动作预览时平滑回正，关闭动画后复位两个偏移，无需新增原生 IPC 或持久化设置。 资源准备脚本补充缺失的水平／垂直 zhuan 控制轨道，不改变供应商关键帧。9 月 9 日资源提供 wuxiong 而缺少 shou1/shou2，经用户确认，点击和释放映射为 wuxiong，其他配置保持不变。设置调试使用独立高优先级动画组，松开后淡出，保留底层语音时钟及正常动画层。 鼠标输入直接写入官方运行库的 zhuan 叠加偏移；水平／垂直动画保留为资源数据，不作为活动跟随层。供应商建议使用比参考图更小的幅度；按用户指定，椭圆范围限制左右位移为 350、上下位移为 300 个骨架单位，身体灵敏度为 2，眼球范围保持不变。骨骼局部 X 对应画面上下、局部 Y 对应画面左右。说话与简洁输入框焦点独立暂停跟随，两者结束后才恢复。同等偏移下，直接控制与两条方向时间轴的骨骼输出基本一致；增强来自范围和灵敏度，未发现时间轴冲突。

插件增加一套运行库，每个活动萌妹渲染器的未压缩贴图约占 32 MiB。设置预览可以与原生桌宠并存，因此渲染器检查覆盖清理和内存上界。移除 ticker 用到了固定版本适配器的内部成员，升级时需要复核。用户提供的角色素材与运行库遵循独立的分发条款。

## Verification

供应商修订的 4096×2048 图集与 PNG 提供独立身体和头发区域，包含 13 个供应商动画及两个应用跟随控制轨道，哈希记录在内置 SOURCE 文件中。使用现有渲染器独立播放可见身体连续、头发不再混入衣物像素，嘴型和闭眼可区分。此源码资源修订需要重新执行标准 Dev 构建才会进入 App。

Host 测试解析全部内置模型；真实装配的浏览器快照包含萌妹，并检查跨引擎切换。龙骨播放测试覆盖交互、表情、四嘴型、本地音频时钟、非空静止画面与反复创建销毁；原生夹具检查穿透、拖动、大小、状态恢复和卸载。Dev 整包测试核对 bundle 和素材一致性，并验证真实 Cordis 加载与原生交互。校准音频仅验证播放时序，不代表任意语音对齐；用户未提供编辑器参考录像，因此不声称逐帧一致。
