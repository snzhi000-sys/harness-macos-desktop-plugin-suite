# Agent Note: 桌宠插件与原生窗口职责

Status: implemented

[English](2026-09-07-desktop-pet.md) | 中文

## Problem

Harness 页面内的角色不能浮在其他应用上方，也不能把透明区域的鼠标输入交给后方窗口。用户提供的单层 PNG 同时缺少 Live2D 面部动画所需的网格和参数。

## Decision

下述 Stable 排除规则已由 [Stable 桌宠](2026-09-09-stable-desktop-pet.md)替代；窗口职责保持不变。

资源、设置、互动状态和浏览器渲染归独立产品插件负责。Electron 增加专用窗口控制器及最小 preload 接口。Cubism 适配器消费触摸、点击、拖拽、释放和待机状态。最初的外置资源、PNG、可编辑配置与会话关联方案由[内置角色选择器](../simplification/2026-09-08-desktop-pet-builtin-picker.md)替代。 左键手势不打开菜单，菜单由右键触发。各渲染器提供适配后稳定的立绘下沿，让输入框贴近角色且不随每帧动作抖动。

## Alternatives considered

**仅在渲染页面叠加角色**不能实现 Harness 外的原生桌面定位，因此只适合作为浏览器预览。

**自动把 PNG 转为 Live2D**会混淆拆层、补画、Cubism 绑定与运行时播放。插件使用现成模型，后续内置角色选择器移除立绘模式。

**打包私人立绘及示例素材**会让可复用插件依赖本地文件及其许可。后续内置角色选择器明确将打包素材限定为本地 Dev 集合。

## Verification

包含七个插件的 Dev Profile 正确加载 Host 与 Client；Stable 排除桌宠包和原生窗口。插件测试、浏览器与原生 Electron 冒烟测试、打包 Dev 冒烟测试均通过。覆盖真实 Cubism 播放、模型动作与表情、物理配置、鼠标穿透、拖拽、偏好恢复和窗口销毁。打包测试先比较执行文件与当前源码及 bundle 的哈希，再进行交互验证。隔离 Dev 构建通过产品组成与升级验证。仓库级 lint 和 doc-sync 仍报告无关的既有问题。

Live2D 的备用肢体依赖动作执行期间的 PartOpacity 曲线。固定版本 Cubism 适配器启用真实部件透明度写入，并将曲线副本按运行库要求的目标类型排序，从而支持混排导出，不修改关键帧，也不猜测每个人物的手臂关系。动作结束后的复位不足以证明播放期间的显隐正确；爱宕播放夹具对预览、自动和普通动作入口逐帧断言部件互斥。

## Consequences

语音播放器负责匹配动作的保持与鼠标跟随暂停。渲染器在普通动作超时后仍保留素材姿态，到音频片段结束、失败或取消才释放，用户直接互动优先。固定延长计时的方案被放弃，因为不同语音长度和暂停仍会造成错误恢复时机。真实龙骨与两代 Cubism 适配器覆盖保持和释放，预览交错不能重新激活已结束的说话动作。气泡括号文字使用克制且可读的浅色，不改变聊天原文，也不解释为标记代码。

亲密度作为完成轮次计数持久化在桌宠私有会话内，等级起止分数和描述为全局可编辑设置。仅在情绪 Prompt 的 `{{亲密情况}}` 处注入，展开后的输入保存在辅助请求中。历史补算被放弃，因为功能上线时即使已有聊天也必须从零开始；全局计数被放弃，因为新建对话必须重置关系。成功且非空的回复在后续情绪生成前只加一次分，测试、失败和中断不加分。每级提供起止分数字段，并拒绝区间重叠或遗漏，避免错误选择描述；仅保存起点的旧设置迁移为等价的明确区间。Host 持久化测试和完整装配的设置快照覆盖迁移、编辑和注入行为。

省略号作为明确语音边界，让后续问句独立进入合成队列，不依赖服务端分句。流式标点串保持完整，中间括号动作归属后一段。用户报告的多括号例句经过过滤后文字完整，真实合成及 ASR 保留尾句。此修改隔离语音片段并增加完整播放回归证据，不宣称复现了偶发漏读。

情绪卫星以五个第一人称字段描述内心感受，不提供回复策略。自定义 Prompt 附带输出规则，仅完全匹配旧默认时替换。结构校验拒绝不完整结果，规范字段分隔但不补造情绪。无效输出保存在辅助请求证据中，不覆盖上次有效情绪。用户参考中的人设与亲密度数值不作为产品默认。

情绪生成以辅助请求保存在聊天消息之外。首轮先生成情绪再回复，后续在完整回复后更新，通过取消与会话身份拒绝旧结果覆盖。情绪历史按双方单条消息计数，默认八条，通过 `{{聊天记录}}` 在有记录的 system Prompt 内按时间顺序和发言者标签展开，替代另一条消息中隐式追加的 JSON 历史；旧限制数值迁移为消息条数，旧自定义模板补入可见变量。对话在发送时固定已完成情绪。按服装保存的字面关键词消费括号旁白，复用可打断播放，不增加模型调用。Prompt 与关键词标签使这些控制与模型连接配置分开。无密钥 Host 并发测试和完整装配的对话快照覆盖这些行为；夹具输出不代表主观情绪效果验收。

Cubism 动作切换时互斥：取消会清理动作队列与旧完成标记，恢复初始参数和 Cubism 3/4 部件透明度，再执行下个动作。没有待机动作的模型也必须复位，因为局部动作不会主动清理未写入的参数。该选择牺牲动作之间的叠加淡入淡出，以保证互斥手臂部件显示一致，单个动作内部的原有变形仍保留。嘴型/肢体字段同时驱动设置分类与自动动作抽选，只有萌妹 a/i/o/m 属于嘴型。显示中的桌宠空闲一分钟后执行非嘴型动作；预览、菜单、拖拽和隐藏/暂停时不能自动触发。用户操作中断、动作结束恢复待机，新一轮计时不补放错过的动作。

插件的私有对话服务由角色下方简洁输入框和设置内嵌的完整聊天页共用。两个入口都延续最近会话及有上限的短期上下文，打开入口不新建会话。方舟文本生成与 V3 TTS/ASR 使用桌宠独立凭据和可编辑 Prompt，主 Harness 模型与会话保持独立。实际模型请求保存在私有记录中，浏览器不接收已保存密钥。单个桌宠页持有播放与嘴型时钟；播放确认让气泡在排队和暂停期间保持，没有朗读的文字采用有上限的阅读时间。收起简洁输入框保留当前轮次，离开聊天记录标签释放采集。原生音频权限限制在所属内嵌页面，不创建额外聊天 BrowserWindow。外观设置保留版本 2，与对话设置分开。

默认和克隆音色选择不同语音资源。已测试音色返回空音素数组，因此采用字时间戳和拼音近似驱动四种嘴型。声音失败或关闭时文字仍可使用。完整短句先缓冲再播放，以一定首音延迟换取音频和字幕同步。测试区分无密钥的服务夹具、真实请求与虚拟麦克风采集；虚拟输入不代表用户物理麦克风已验收。 连续归一化状态权重使用官方网格融合，替代反复启动短时嘴型淡入淡出；身体跟随由原有方向时间轴驱动，说话派生状态排除嵌套方向轨道，使两种控制独立。这保留了素材网格，不引入另一套动画引擎。 说话时嘴型权重归一化；默认和整句结束后的四个说话状态权重均为 0，结束用 0.2 秒淡出恢复待机嘴形。m 只用于说话中的闭口过渡，不作为静止嘴形。固定版本兼容修正让已完成的单帧 FFD 继续参与权重融合；待机未覆盖的内嘴槽使用零形变底层，防止残留。

语音文本投影过滤嵌套括号旁白，不修改可见回复和日志原文。标点不分占发音时长，部分缺失字幕在可用时间空隙补齐，不兼容的时间轴明确降级。短音节缩短标准 200 毫秒融合，使下一嘴型到来前能张嘴。音色 ID 决定默认或克隆资源，「保存并试听」先提交当前表单再合成，加载期间禁止编辑，避免迟到配置覆盖输入。

当前内置清单与用户导入入口移除由内置角色选择器记录负责。本地调研下载固定仓库提交，即使经过分发镜像仍验证 blob 哈希。

Cubism Core 和模型许可独立于插件源码。渲染器分别提供 Cubism 2、Cubism 3/4 适配器，不保证所有新版模型特性。原生透明区域输入必须同时在完整桌面产品和可控 Electron 测试中检查。桌面代码及产品清单的现有工作树修改必须在集成中保留。

Client bundle 通过 `globalThis.__ModuleLoader__.load` 注册延迟 CommonJS 工厂；普通 ESM 会破坏 Harness 加载。构建契约检查固定这一要求。Host 配置使用 Schemastery 默认值，已保存的本地偏好优先。本地 `dsh-desktop-pet:react` 事件接受 touch 与 click 动作，无需模型请求。

原生控制器负责窗口边界、透明度与生命周期。隐藏会销毁渲染器；卸载插件和退出应用会释放资源。Live2D 透明度命中检测需要翻转 WebGL 像素的 Y 坐标。内置角色选择器负责资源清单和旧素材设置迁移。

Session 权限处理器同时影响主窗口和桌宠。仅允许媒体权限会拒绝普通 Explorer 复制操作，因此剪贴板写入明确允许主窗口的后端来源，读取仍被拒绝。真实 Electron 夹具通过共用 UI helper 回放文件和文件夹路径写入快照，并比较原生剪贴板内容；它不代替 Explorer 菜单交互验证。

动作使用明确的组名和索引，支持空动作组。循环动作有播放上限，重复动作和表情允许再次触发。原有动画保留主要参数控制权，视线仅低权重叠加。没有标准命中区域时使用可校准的头部区域。每个内置角色提供预设动作配置，缺失依赖会拒绝构建，原始素材不修改。

设置关闭释放预览，休眠释放原生窗口；唤醒须满足显示偏好和有效租约。Retina 透明度校准直接按物理尺寸读取 WebGL 缓冲，避免 Pixi 提取器重复应用像素倍率。
