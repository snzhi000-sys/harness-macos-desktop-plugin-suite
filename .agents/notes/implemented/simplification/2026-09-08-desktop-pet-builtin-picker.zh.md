# Agent Note: 内置桌宠角色选择器

Status: implemented

[English](2026-09-08-desktop-pet-builtin-picker.md) | 中文

## Problem

角色数量增加后，长卡片列表将设置和按钮挤出视口。保留的搜索词和技术筛选容易让用户以为只能选择三个角色。目录、Core、PNG 模式和动作绑定要求用户先配置才能使用，偏离了直接选择伙伴的需求。

## Decision

采用独立滚动并支持搜索的角色列表，旁边保留一个实时立绘和基础设置。点击角色行立即保存并切换；保存提交大小、动画和置顶，不改变显示状态。显示和隐藏单独控制可见性，右上角关闭按钮及 Escape 释放预览。紧凑窗口中底部操作依然可见。

本地 Dev 插件包含 22 个 Live2D 版本与萌妹、预设动作、缩略图和 Cubism 驱动，以相对路径和稳定标识的资源清单为准。开发者更新清单并重新打包，用户数据只保存基础偏好，不承担必需素材来源。本决策替代[原生窗口所有权记录](../feature/2026-09-07-desktop-pet.md)中的外置素材和 PNG 模式方案。

产品移除 PNG 渲染、直接路径与 Core 字段、技术筛选、目录导入、动作配置和会话关联。版本 1 磁盘设置迁移保留大小和开关，并按旧私人索引中的名称匹配内置角色；私人文件不删除，只写入版本 2 字段。当前 HTTP 写入拒绝已移除字段。

## Alternatives considered

**将技术设置藏入高级面板**仍保留配置负担与不用的渲染路径，用户已明确要求移除这些能力。

**扩大卡片网格**仍会与立绘和设置争夺纵向空间。独立列表让所有角色可达，同时保持操作可见。

**直接把用户模型库打入插件**可能夹带私人路径和设置。资源整理脚本改为使用固定调研来源与已确认的播放配置。本地 Dev 打包与公开分发仍是两件事。

## Verification

空数据的真实 Client 快照与浏览器检查覆盖 19 个角色项及 23 套造型、列表末项、搜索与空结果、两种窗口尺寸、基础设置、Escape、关闭按钮、延迟切换完成和卸载。Host 测试检查旧字段及入口拒绝、偏好迁移和资源路径限制。原生检查覆盖透明穿透、拖动、大小调整、暂停帧、重启、显示隐藏和卸载。打包检查使用空用户数据，核对包内源码和清单哈希，并播放内置模型。

## Consequences

服装版本不等于独立人物。已确认的 Mori 与户山香澄服装归到同一角色项；换装复用串行角色切换并保存稳定 ID，不增加偏好字段。身份未确认时保持独立，衣服物理参数本身不能证明素材具有换装动作。动作能力仍由模型决定，不自动补出缺失绑定或表情。源码可复用，但构建前必须准备 Git 忽略的本地资源，资源包不构成公开分发授权。资源更新需要重新构建 Dev。每个弹窗只有一个预览，关闭或卸载后迟到结果不能恢复预览。设置修改串行执行，避免保存基础设置覆盖同时发生的角色选择。
