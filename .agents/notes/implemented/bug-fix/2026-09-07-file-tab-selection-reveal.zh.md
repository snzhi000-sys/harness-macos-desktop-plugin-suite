# Agent Note: 在标签滚动区显示当前文件标签

Status: implemented

[English](2026-09-07-file-tab-selection-reveal.md) | 中文

## Problem

选择 File Edit 标签栏可视区域之外的文件时，正文已显示，但对应标签仍被隐藏。

## Decision

FileView 在选择提交到 DOM 后显示活动标签，独立打开计数也覆盖重复打开同一文件。只以最小必要距离横向滚动标签区；超宽标签对齐开头。常规审核更新与拖动排序不触发定位。重新挂载文件视图或切换会话时显示当前标签。

## Alternatives considered

**每次 store 更新都滚动。** 否决，因为轮询和编辑会覆盖用户手动浏览标签的位置。

**使用 scrollIntoView。** 否决，因为它可能同时滚动祖先容器，干扰正文阅读。

## Consequences

后续选择使用 180–250ms 三次减速动画。新选择取消旧帧并从当前位置出发；滚轮、指针、触摸、拖动和键盘输入中止动画但不阻止事件。首次挂载、会话恢复和减少动态效果模式直接定位。effect 清理取消动画帧并移除输入及媒体偏好监听。不使用原生平滑滚动，因为其时长和中止行为随浏览器变化。

修改仅涉及客户端，不改变文件权限、审核状态或标签顺序。几何测试覆盖左右边界、无需滚动、超宽和隐藏标签；集成检查约束打开信号与已提交引用。仅调整窗口大小不会强制定位，下次激活文件时执行。
