# Agent Note: 冷会话文件浏览不加载历史

Status: implemented

[English](2026-09-07-cold-session-file-open.md) | 中文

## Problem

Explorer 可以在 Host 会话挂载前显示文件。File Edit 拒绝该会话后，文件路由把失败当作下载请求。审核水合也可能拖慢无关文件的浏览。

## Decision

只读目标解析及差异浏览从已挂载会话头或持久化服务的仅头信息列表取得根目录，不加载对话日志、不等待审核水合、不信任客户端 cwd。这不会标记审核基线就绪或授予写入策略。路由区分读取错误与已确认二进制；迟到的客户端打开结果不得激活其他会话。

## Alternatives considered

**等待历史挂载。** 否决，因为文件读取不需要模型历史。

**信任 Explorer cwd。** 否决，因为客户端路径不能替代 Host 权威信息。

**所有失败都下载。** 否决，因为网络和启动错误不能说明文件格式。

## Consequences

冷浏览只需要元数据 I/O 与目标文件读取。不存在的会话仍被拒绝，写操作保持既有检查。测试覆盖未挂载会话、禁止执行的历史加载器、不可信 cwd，以及打开和探测失败不下载。
