# Agent Note: 空白会话中的外部视图

Status: implemented

[English](2026-08-17-blank-session-external-conversation-views.md) | 中文

## 问题

空白会话 Hero 会隐藏会话标题栏，并让严格会话主体不渲染。插件原先只能查找并点击已经渲染的标签按钮来打开自己的会话视图，但新建空白会话中根本不存在该按钮。因此 Explorer 打开文件时只更新了插件本地状态，界面没有显示文件；文件插件的全局状态还可能保留上一个会话的当前文件。

## 决策

`ConversationController` 现在提供按 scope 寻址的 `activateView(viewId)`。按会话隔离的激活协调器为常驻壳镜像当前视图 id，将其绑定到框架拥有的 chat store，并把 store 挂载前发出的请求排队。外部视图不会改变 Host 的 blank 标志，也不会合成会话内容。

常驻壳在选择布局时读取镜像视图。空白 Chat 仍保留居中 Hero，并隐藏标题栏与主体。空白会话选中外部视图时使用 active 布局，显示普通标题栏和请求的视图，并让同一个编辑器保持底部姿态；切回 Chat 后恢复 Hero。

Explorer 打开请求会携带目标会话 id、已解析 cwd、绝对路径和工作区相对路径。文件插件先把内存标签集切换到目标会话，再打开文件并通过控制器激活视图；每个会话分别缓存标签页和当前文件。

## 验证

定向 UI 测试覆盖了空白 Chat 行为不变，以及空白会话渲染外部视图。协调器测试覆盖挂载前请求、持久化选择和会话隔离。会话客户端类型检查与定向测试均通过；Better Sidebar 类型检查和构建通过，文件插件客户端 bundle 构建通过。

## 后果

会话视图插件不再依赖本地化标签文字或已渲染 DOM 来激活自身。空白会话可以承载非 Chat 工具而不会变成非空会话，文件标签也不会在浏览器运行期间跨任务泄漏。
