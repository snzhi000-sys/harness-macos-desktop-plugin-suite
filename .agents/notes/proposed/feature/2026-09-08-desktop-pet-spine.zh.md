# Agent Note: Spine 桌宠角色准入

Status: proposed

[English](2026-09-08-desktop-pet-spine.md) | 中文

## Problem

供应商的 Spine 4.2 导出包含空嘴型时间轴、不一致的贴图区域和重复约束顺序。解析成功不能证明组装正确；目前无法取得供应商的可编辑工程。

## Proposal

保留龙骨实现，增加独立官方 Spine WebGL 驱动。只有原始素材或可追溯派生副本通过实际播放验收后才接纳角色。素材修复期间保持现有设置和 25 项清单。驱动源码已存在，但没有将 Spine 角色入库或作为交付包发布。

## Alternatives considered

替换龙骨会丢失独立对照；直接注册有问题的导出会重复组装缺陷。根据匹配的龙骨绑定姿态恢复变形优于凭空编造嘴型，但裁掉发丝的贴图裁切不能作为原作恢复。

## Acceptance criteria

正常 Dev 交付前要求身体和头发完整组装、原有嘴型可区分、约束调度正确、动画混合与原生生命周期验证通过。描述符拒绝配置中的空时间轴与重复约束顺序。浏览器播放及驱动生命周期检查不代替视觉验收。

## Risks

缺失的约束顺序无法直接说明作者原来的排序；绑定姿态与初始姿态的差异可能有意为之。运行库与角色分别遵循自身许可。[插件 README](../../../../plugins/desktop-pet/README.md) 说明资源准备和驱动行为；现有[龙骨决策](../../implemented/feature/2026-09-08-desktop-pet-dragonbones.md) 继续有效。
